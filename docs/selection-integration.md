# 选怪页面融合

视觉来源：用户提供的 monster-arena.zip，2026-10-24。沿用三栏图鉴/舞台/详情、皮革与黄铜材质、铸铁画框、主题色和系统字体。样式限定在 .summoner 内，不影响对战画板和手势输入。

中央舞台继续使用 assets/models/ 下三个原始怪兽和竞技场。选中一个怪兽时聚焦该模型；大厅展示三只，对战展示双方所选模型。界面不加载原演示的 SVG 替代怪兽，也不引入其未绑定怪兽、货币、升级和虚构装备数值。

入场窗口使用原生 dialog，保留键盘焦点、Escape 关闭和背景不可操作行为；选择结果传给原有建房、准备与服务端状态。邀请链接直接打开加入窗口。1–3 选怪仅在首页生效，1–6 战斗快捷键保留。实际生命、六个技能及冷却从 src/pvp/rules.js 读取。

浏览器验证：三种模型切换、方向键选怪、建房与加入、双方准备、保留所选 rock/fire 并开始对战，数字键 1 施放火球术后双方同步 22 伤害，离开后回到选怪页面，控制台无 warning/error。
